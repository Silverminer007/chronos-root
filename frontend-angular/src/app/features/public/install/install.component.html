Was ist eine PWA?

Eine Progressive Web App (PWA) ist eine Website, die wie eine native App funktioniert. Nach der Installation erhältst du:

  • Schnellerer Zugriff – Öffne Chronos direkt vom Startbildschirm
  • Push-Benachrichtigungen – Erhalte Erinnerungen an wichtige Termine
  • Vollbild-Modus – Nutze die App ohne Browser-Oberfläche
  • Kein App Store nötig – Installiere direkt aus dem Browser
