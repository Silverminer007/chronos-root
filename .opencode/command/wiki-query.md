description: Frage anhand von Wiki und docs/ beantworten, gegen den Code prüfen und Wertvolles zurückschreiben
argument-hint: <Frage>

Beantworte `$ARGUMENTS`: zuerst `wiki/index.md` lesen, passende Wiki-Seiten und `docs/` laden, Code-abhängige Aussagen gegen den Code prüfen. Quellen nennen. Hat die Antwort bleibenden Wert, als Wiki-Seite zurückschreiben (Index und Log ergänzen).
