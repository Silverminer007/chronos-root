## Description

**All user-facing text and error messages must be in German.** This includes:
- Button labels
- Form placeholders
- Error messages
- Tooltips
- Help text
- Notifications (toast messages)
- Page titles and headings

## Rationale

Chronos targets **youth organizations in German-speaking regions** (primary market: Germany, Austria, Switzerland). Users expect a native German experience, not English UI with German content.

This is a non-negotiable business requirement — the target demographic expects German, and English UI is a user experience blocker.

## Implications

### Code
- All hardcoded strings must be in German
- No English strings in components/templates
- Error messages from backend should be German or mapped to German in frontend
- Toast/notification messages must be German

### Localization
- No i18n library needed (single language)
- If multi-language support is added later, would require refactoring (ADR change)

### Backend Error Messages
- Backend sends error codes (e.g., `APPOINTMENT_NOT_FOUND`)
- Frontend maps codes to German messages
- Backend never sends user-facing text (technical errors only)

### Testing
- E2E tests should verify German text is present
- No hardcoded English in tests

### Example

**❌ Wrong:**
```vue
<button>Save</button>
<span v-if="error">Error: Appointment not found</span>
<p>Please enter a title</p>
```

**✓ Correct:**
```vue
<button>Speichern</button>
<span v-if="error">Fehler: Termin nicht gefunden</span>
<p>Bitte geben Sie einen Titel ein</p>
```
