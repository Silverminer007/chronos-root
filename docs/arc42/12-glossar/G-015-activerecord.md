# G-015: ActiveRecord

**Begriff:** ActiveRecord

ORM pattern where entities have query methods directly (e.g., `Appointment.findById(1)`). Used by Panache. Opposite of Repository pattern. (Quelle englisch, aus `kb/glossary/glossary.md`.)
