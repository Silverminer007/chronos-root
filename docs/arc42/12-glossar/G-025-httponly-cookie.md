# G-025: httpOnly Cookie

**Begriff:** httpOnly Cookie

Cookie inaccessible to JavaScript (set with `HttpOnly` flag). More secure than JavaScript-accessible cookies. Chronos stores auth tokens in httpOnly cookies. (Quelle englisch, aus `kb/glossary/glossary.md`.)
