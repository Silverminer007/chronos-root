# G-002: Terminstatus

**Begriff:** Terminstatus

**Code-Name:** `AppointmentStatus`: `PLANNED`, `CANCELLED`, `DELETED`, `NOT_ENOUGH_ATTENDEES`

Zustand eines Termins; `NOT_ENOUGH_ATTENDEES` gilt, wenn zu wenige Zusagen vorliegen.
