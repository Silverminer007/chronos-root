# G-026: JWT

**Begriff:** JWT

JSON Web Token. Token format used by Keycloak. Contains encoded claims (user ID, expiry, etc.) signed by Keycloak. Validated by backend. (Quelle englisch, aus `kb/glossary/glossary.md`.)
