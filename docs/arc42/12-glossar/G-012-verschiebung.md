# G-012: Verschiebung

**Begriff:** Verschiebung

**Code-Name:** `AppointmentMovedEvent` (Java); `APPOINTMENT_MOVED` (Rust); Einstellung `appointment_moved` (Frontend)

Änderung von Start oder Ende eines Termins; löst Push-Benachrichtigung und Systemnachricht aus.
