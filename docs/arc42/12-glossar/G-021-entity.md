# G-021: Entity

**Begriff:** Entity

Hibernate JPA entity. Represents a row in the database (Appointment, User, etc.). Decorated with `@Entity` and extends `PanacheEntity`. (Quelle englisch, aus `kb/glossary/glossary.md`.)
