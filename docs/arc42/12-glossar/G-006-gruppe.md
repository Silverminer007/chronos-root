# G-006: Gruppe

**Begriff:** Gruppe

**Code-Name:** `Group` (Java, Rust, Frontend)

Benannte Menge von Benutzern mit Besitzer (`ownerOidcId`), die gesammelt zu Terminen eingeladen werden kann.
