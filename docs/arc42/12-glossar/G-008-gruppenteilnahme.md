# G-008: Gruppenteilnahme

**Begriff:** Gruppenteilnahme

**Code-Name:** `AppointmentGroupParticipation` (Java); `ParticipantGroup` (Frontend)

Einladung einer ganzen Gruppe zu einem Termin; die Mitglieder erhalten daraus eigene `AppointmentParticipation` (`groupParticipationId`).
