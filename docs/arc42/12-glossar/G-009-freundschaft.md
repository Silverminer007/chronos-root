# G-009: Freundschaft

**Begriff:** Freundschaft

**Code-Name:** `FriendshipRequest` (Java, Frontend); `FriendshipStatus`: `PENDING`, `ACCEPTED`, `DECLINED`; `Friend` (Frontend)

Anfrage zwischen zwei Benutzern; angenommen (`ACCEPTED`) sind die Benutzer befreundet.
