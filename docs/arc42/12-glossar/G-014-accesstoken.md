# G-014: AccessToken

**Begriff:** AccessToken

JWT (JSON Web Token) that proves a user is authenticated. Issued by Keycloak, expires quickly (5 mins typical), stored in httpOnly cookie. Used to authenticate requests to the backend. (Quelle englisch, aus `kb/glossary/glossary.md`.)
