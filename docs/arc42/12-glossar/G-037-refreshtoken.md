# G-037: RefreshToken

**Begriff:** RefreshToken

Long-lived JWT used to obtain new access tokens. Stored in httpOnly cookie. Never directly used by frontend (Service Worker handles refresh). (Quelle englisch, aus `kb/glossary/glossary.md`.)
