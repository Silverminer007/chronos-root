# G-016: OIDC

**Begriff:** OIDC

OpenID Connect. Authentication protocol built on OAuth 2.0. Chronos uses OIDC for secure user authentication via Keycloak. (Quelle englisch, aus `kb/glossary/glossary.md`.)
