# RA-010: Betrieb und Entwicklung hängen an einer Person

**Risiko:** Code-Owner, Betreiber (Impressum) und fast alle Commits gehen auf eine Person zurück; Agenten ersetzen keine menschliche Freigabe. Fällt die Person aus, ist weder Betrieb noch Freigabe von `docs/` gesichert. Eine Vertretung ist nicht belegt ([RA-013](RA-013-vom-product-owner-festzulegende-werte-und-entscheidungen.md)).

**Wahrscheinlichkeit / Schaden:** **(?)** / hoch. **Maßnahme:** Vertretung und zweiten Code-Owner benennen.
