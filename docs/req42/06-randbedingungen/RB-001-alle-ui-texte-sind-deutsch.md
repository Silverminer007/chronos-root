# RB-001: Alle UI-Texte sind deutsch

Alle nutzersichtbaren Texte und Fehlermeldungen sind auf Deutsch; es gibt keine i18n-Bibliothek. Das Backend sendet Fehlercodes, das Frontend bildet sie auf deutsche Texte ab.
