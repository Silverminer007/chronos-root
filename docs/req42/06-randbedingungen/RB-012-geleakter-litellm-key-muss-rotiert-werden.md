# RB-012: Geleakter LiteLLM-Key muss rotiert werden

Ein in der Git-Historie enthaltener LiteLLM-Key gilt als kompromittiert; die Historie wird bewusst nicht umgeschrieben. Offene Aufgabe für den Besitzer: Key rotieren.
