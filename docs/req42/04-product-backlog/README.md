# Product Backlog

Ebenen: [Features](features/README.md) (`F-nnn`, Funktionsumfang) und [Anforderungen](anforderungen/README.md) (`FA-nnn`, Stories mit Akzeptanzkriterien). Verweisrichtung: Anforderung → Feature → Ziel und Stakeholder. Diese Ebenen beschreiben den **Ist-Zustand**; noch nicht umgesetzte Epics und Stories stehen als offene GitHub-Tickets in der [Roadmap](../11-roadmaps/README.md). Rang und Priorität der Einträge legt der Product Owner fest ([RA-013](../12-risiken-annahmen/RA-013-vom-product-owner-festzulegende-werte-und-entscheidungen.md)); die Einträge sind bis dahin nach ID geordnet. Definition von Epic, Feature, User-Story und Task samt Ticketstruktur und Definition of Done: [Ticket-Typen](ticket-typen.md). Modelle zum Verständnis: [05-modelle](../05-modelle/README.md).
