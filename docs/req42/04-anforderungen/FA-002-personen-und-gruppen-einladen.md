# FA-002: Personen und Gruppen einladen

Benutzer können Freunde und ganze Gruppen zu einem Termin einladen.

## Akzeptanzkriterien
- Eingeladen werden können nur befreundete Benutzer (Freundschaftsprüfung).
- Beim Einladen einer Gruppe erhalten alle Mitglieder eine eigene Teilnahme.
- Einladungen können wieder entfernt werden.
